# Dungeon map sources

[Return to the guide index](../README.md)

Downloaded for the 31 October 2026 research snapshot. These are attributed reference images, not newly surveyed layouts. The new-dungeon maps are fan recreations credited to Santiago Reyes, Atlas de Azeroth: Forever. Returning-dungeon images are annotated Classic references; their geometry and boss locations have not been independently verified in Forever. Original credits remain in the images where present.
